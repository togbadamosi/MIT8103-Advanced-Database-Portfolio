# Portfolio 5: Distributed and Cloud Database
## Overview
Portfolio 5 examines distributed and cloud database concepts using the fictional ApexPetro Energy Limited Operations & Maintenance Management System developed throughout the MIT 8103 portfolio.

The scenario considers how database services could support multiple fictional operational locations:

Alpha Processing Facility

Bravo Flow Station

Delta Storage Terminal

Echo Production Facility

The portfolio considers database distribution, replication, availability, consistency and cloud deployment within this scenario.

All organisations, locations, records and architectural scenarios used in this portfolio are fictional and created solely for academic purposes.

## Portfolio 5 Objectives
This portfolio will address:

A distributed/cloud database architecture for the ApexPetro scenario.

Database replication and availability.

Data distribution and sharding considerations.

Consistency requirements for different categories of operational data.

Relevant cloud/deployment evidence where practically implemented.

Technical analysis and reflection.

Relationship with Previous Portfolios

Portfolio 5 builds on the database work completed in the previous activities:

Portfolio 1 established the relational database design.

Portfolio 2 demonstrated query processing and optimisation.

Portfolio 3 demonstrated transaction management and concurrency control.

Portfolio 4 introduced a document-oriented NoSQL model for equipment inspection and condition-monitoring information.

Portfolio 5 extends the case study by considering how these database services could operate in a distributed and cloud-based environment.
