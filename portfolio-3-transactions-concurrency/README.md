# Portfolio 3: Transactions and Concurrency
## Overview
Portfolio 3 applies transaction-management and concurrency-control techniques to the ApexPetro Energy Limited Operations & Maintenance Management System.

The activity will demonstrate:

1. A successful multi-step transaction using COMMIT.
2. Reversal of uncommitted database changes using ROLLBACK.
3. Transaction isolation.
4. A concurrency issue or control mechanism.
5. Practical execution and output evidence.

The transaction scenarios build on the relational schema developed in Portfolio 1 and the synthetic data created in Portfolio 2.

All records and scenarios used in this portfolio are fictional and created solely for academic purposes.
