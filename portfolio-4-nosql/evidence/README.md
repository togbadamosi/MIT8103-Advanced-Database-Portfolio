# Portfolio 4 Evidence
This folder contains practical evidence supporting the NoSQL document-model implementation for the ApexPetro Equipment Inspection and Condition Monitoring use case.

## Evidence Index
00-nosql-document-insertion.png - Confirms insertion of the eight synthetic inspection documents.

01-attention-required-query.png - Shows the query for inspections with the condition Attention Required.

02-embedded-asset-query.png - Demonstrates querying the embedded asset.asset_name field.

03-embedded-measurement-query.png - Demonstrates querying an equipment-specific embedded vibration measurement.

04-compressor-temperature-query.png - Demonstrates numerical filtering against the embedded compressor temperature field.

05-document-update.png - Shows the updated INS-002 document with the additional maintenance recommendation.

06-condition-aggregation.png - Shows aggregation of inspection documents by condition.

07-equipment-type-aggregation.png - Shows aggregation by embedded equipment type with conditional counting.
