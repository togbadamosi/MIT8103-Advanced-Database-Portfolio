# AI Use Declaration
Microsoft 365 Copilot was used as a learning, drafting and technical-assistance tool during the development of this MIT 8103 Advanced Database Systems portfolio.

Using AI to support the following:

1. Support the interpretation of the requirements and organisation of the portfolio structure.

2. Help develop and polish fictional ApexPetro Energy Limited case study.

3. Help to draft and review database business rules, relational modelling and normalisation explanations.

4. Help develop, troubleshoot and improve SQL queries and database-testing scenarios.

5. Help with transaction, isolation and concurrency-control demonstrations.

6. Help develop the NoSQL document model, MongoDB queries and corresponding analysis.

7. Take part in development and explanation of the distributed and cloud database architecture.
8. Advise on organisation of GitHub portfolio and technical documentation.
9. Help clarify, structure and present the final product documentation.
10. There were no AI-generated suggestions that were accepted without being reviewed against the selected ApexPetro case study, as they were only executed successfully.

The student practically implemented and verified the relational database schema, SQL queries, transaction tests and NoSQL operations. The results of the queries were reconciled, discrepancies were identified and fixed and screenshots of actual implementation results were kept as evidence.

The student examined the case study, database design, business rules, ER model, relational schema, SQL queries, normalization analysis, transaction tests, NoSQL model, distributed/cloud architecture and documentation.

The student agrees to be responsible for the correctness, originality, comprehension and interpretation of all the work included in this portfolio.
